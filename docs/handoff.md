## Key rules (from the doc)
- Access is only through dashboard groups: one live group per user per dashboard. The group's RLS value is the Power BI role name (several roles comma-separated).
- Owner approval is always required for access requests, and for every addition of people to an access group (C26): one request per add action, owners approve all or only the people they tick. A Super Admin can override only from the Admin Portal's Access Requests page, with a recorded reason.
- If RLS is on, every group (incl. default) must have an RLS value. The Dashboard Owner role is assigned automatically.
- Retire soft-deletes in the portal and deletes the Power BI asset. If both owners leave, the dashboard becomes Inactive.
- Clone copies members only. Limits: 12 pins, 8 tags (10 alphanumeric characters each). Thumbnails 16:9 PNG/JPG ≥640x360, ≤1 MB.
- GenAI dashboards are a single HTML file from an approved template, up to 5MB; approved CDNs are cdnjs and jsdelivr. Branding is configurable in Admin Config.
